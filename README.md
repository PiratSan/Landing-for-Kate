# Landing for Kate

Персональный лендинг Екатерины, специалиста по таргетированной рекламе.

Приложение работает во внутреннем Docker-контейнере, а Caddy принимает внешние HTTP/HTTPS-запросы.

## Разработка

```powershell
npm install
npm run dev
```

Перед публикацией:

```powershell
npm run lint
npm run build
```

## Публикация

Production-образ собирается на локальном компьютере для `linux/amd64`. VPS получает уже готовый образ и только перезапускает контейнеры — сборка на сервере не выполняется.

Из ветки `main` с чистым рабочим деревом:

```powershell
.\scripts\deploy.ps1
```
